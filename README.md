# 🚨 Elderly Fall Detection System

An IoT-based wearable device and system designed to detect accidental falls in elderly individuals and immediately alert caregivers or emergency services.

### 📌 About the Project
Falls are a major health risk for the elderly. This project aims to minimize response time during such emergencies by using real-time motion tracking. By continuously monitoring the user's movements, the system identifies sudden impacts and changes in orientation that indicate a fall.

### ✨ Key Features
* **Real-time Monitoring:** Continuously analyzes motion using an accelerometer and gyroscope.
* **Fall Recognition Algorithm:** Differentiates between normal daily activities (like sitting or walking) and actual falls.
* **Instant Alerts:** Triggers a buzzer and sends an emergency notification when a fall is detected.

### 🛠️ Hardware & Components
* Microcontroller (e.g., Arduino Uno)
* MPU6050 (6-axis Accelerometer and Gyroscope)
* Buzzer for local alarm

### 💻 Software & Technologies
* **Language:** C++ (Arduino IDE)
* **Libraries:** MPU6050, Wire.h

### 🚀 How to Run the Project
1. Clone this repository to your local machine.
2. Open the `fall_detection.ino` file using the Arduino IDE.
3. Install the MPU6050 library via the Library Manager.
4. Upload the code to your microcontroller.
